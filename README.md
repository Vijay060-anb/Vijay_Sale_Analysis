Interactive Excel Dashboard for Sales Analysis using Pivot Tables, Pivot Charts, Slicers, Descriptive Statistics and Correlation Analysis.
# Excel Sales Dashboard

## Project Overview
This project analyzes supermarket sales data using Microsoft Excel.

## Features
- Data Cleaning
- Descriptive Statistics
- Correlation Analysis
- Pivot Tables
- Pivot Charts
- KPI Cards
- Interactive Slicers

## Key Insights
- Quantity sold is the strongest driver of revenue.
- Food & Beverages generates the highest revenue.
- Members contribute more revenue than normal customers.
- Customer ratings have little impact on revenue.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Correlation Analysis
- Descriptive Statistics
